# 🐱🐶 流浪猫狗寻回领养救助平台

一款公益类微信小程序，面向**走失宠主**、**捡到流浪动物的热心市民**和**线下流浪动物救助机构**，提供寻宠/拾宠上报、领养智能匹配、救助站管理和 **AI 短视频素材一键生成**等功能。

> 📌 纯前端 Demo 版本，无需后端服务器，本地 + 微信开发者工具即可运行。

---

## ✨ 核心功能

### 🔍 模块1：寻宠/拾宠上报
- 家养宠物走失 / 野外捡到流浪动物，二选一填报
- 表单包含：名称、品种、毛色、年龄、受伤情况、描述、联系电话
- 自动 GPS 定位 + 手动修改地址
- 多图上传（最多6张）
- 提交后自动生成标准寻宠/拾宠卡片

### 💕 模块2：领养智能匹配
- 领养人填写申请表（城市、住房类型、养宠经验、空间、偏好品种）
- AI 标签权重匹配算法，智能推荐最适合的待领养宠物
- 支持收藏心仪宠物、在线留言咨询

### 🏥 模块3：救助站后台
- 救助机构账号登录（演示账号：`admin` / `123456`）
- 数据看板：查看全部寻宠/拾宠/领养统计
- 宠物管理：新增/编辑/上架下架/删除收容宠物
- 活动公告：发布线下救助活动、公益募捐公告

### 🎬 模块4：AI 短视频一键生成（核心特色）
- 任意宠物详情页点击「生成短视频素材」
- **优先调用 DeepSeek API 智能生成**，失败自动降级到本地文案模板
- 输出内容：
  - ✅ 温情寻宠文案 / 领养科普文案（2套）
  - ✅ 5镜分镜描述
  - ✅ 抖音/小红书爆款标题
  - ✅ 话题标签
  - ✅ 排版建议 + BGM 推荐
- 支持一键复制导出，直接用于剪映/CapCut 等剪辑软件

## 🚀 快速开始

### 前置条件
1. 下载并安装 **[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)**
2. 注册微信小程序账号，获取 **AppID**（[注册地址](https://mp.weixin.qq.com/)）
3. （可选）注册 **[DeepSeek API Key](https://platform.deepseek.com/)**，用于 AI 智能文案生成

### 运行步骤

```bash
# 1. 克隆项目
git clone <your-repo-url>
cd stray-pet-rescue

# 2. 打开微信开发者工具
# 3. 选择「导入项目」，目录选择 stray-pet-rescue 文件夹
# 4. 填入你的 AppID（或选择「测试号」）
# 5. 点击「确定」，即可在模拟器中预览
```

### 配置 AI 文案生成

1. 打开小程序 → 底部「领养」标签 → 滑到底部「🔑 AI 文案生成设置」
2. 输入你的 DeepSeek API Key（格式：`sk-xxxxxxxxxxxxxxxx`）
3. 保存后，在任何宠物详情页点击「生成短视频素材」即可使用 AI 智能生成

> 如不配置 API Key，系统将自动使用本地预设文案模板，仍可正常使用。

## 📁 项目结构

```
stray-pet-rescue/
├── app.js                    # 小程序入口
├── app.json                  # 全局配置（路由/窗口/TabBar）
├── app.wxss                  # 全局样式（暖色系主题）
├── pages/
│   ├── index/                # 首页（四大模块入口 + 数据统计）
│   ├── report/

│   │   └── form/             # 上报表单
│   ├── adopt/
│   │   ├── index/            # 领养列表 + API Key 配置
│   │   ├── form/             # 领养申请表
│   │   └── match/            # 智能匹配结果
│   ├── detail/               # 宠物详情（含留言咨询）
│   ├── video-gen/            # AI 短视频素材生成
│   └── shelter/
│       ├── login/            # 救助站登录
│       ├── dashboard/        # 数据看板
│       ├── manage/           # 宠物管理（增删改）
│       └── activity/         # 活动/公告管理
├── components/
│   ├── pet-card/             # 宠物卡片组件
│   └── navbar/               # 自定义导航栏
├── custom-tab-bar/           # 自定义底部导航
└── utils/
    ├── storage.js            # 本地存储封装
    ├── mock-data.js          # Mock 数据（首次启动自动载入）
    ├── match-engine.js       # 领养匹配算法
    ├── ai-api.js             # DeepSeek API 调用
    ├── template-text.js      # 本地文案模板（AI 兜底）
    └── util.js               # 通用工具函数
```

## ⚠️ 注意事项

- **数据存储**：所有数据存储在手机本地缓存（wx.Storage），清除微信数据会丢失
- **图片存储**：图片以 base64 格式存储，数量较多时可能占用较大空间
- **地图定位**：需要用户授权位置权限，首次使用会弹出授权提示
- **API Key**：DeepSeek API Key 仅存储在本地，不会上传任何服务器
- **正式上线**：含「公益」「募捐」等类目，正式上线需提供相关资质
