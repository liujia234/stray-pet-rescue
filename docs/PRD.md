## 一、产品概述

### 1.1 产品定位
面向**走失宠主、热心市民、救助机构**三方用户的公益类微信小程序，核心差异化为 **AI 短视频素材一键生成** + **领养智能匹配**。

### 1.2 核心价值主张
> "让每一只流浪动物，都有机会被看见"

| 用户角色 | 核心痛点 | 解决方案 |
|----------|----------|----------|
| 🐱 走失宠主 | 寻宠信息传播效率低，渠道分散 | 一键生成寻宠卡片 + AI 短视频素材，多平台裂变 |
| 🤝 热心市民 | 捡到流浪动物不知如何处理 | 标准化上报表单 + 自动匹配附近救助站 |
| 🏥 救助机构 | 领养转化率低，宣传成本高 | AI 智能匹配领养人 + 免费视频素材降低宣传门槛 |

### 1.3 目标用户画像

| 画像 | 年龄 | 场景 | 核心需求 |
|------|------|------|----------|
| 都市养宠白领 | 22-35 | 宠物走失 | 快速扩散信息、找回宠物 |
| 爱心市民 | 18-50 | 捡到流浪动物 | 找到主人或移交救助 |
| 救助站工作人员 | 25-60 | 日常管理 | 高效管理、提高领养率 |
| 领养意向用户 | 20-40 | 想养宠物 | 找到合适的宠物 |

## 三、核心流程

### 3.1 寻宠启事发布流程
```
宠主打开小程序 → 点击"寻宠上报"
  → 填写宠物信息（品种/毛色/年龄/描述）
  → GPS 自动定位 + 手动修改地址
  → 上传宠物照片（最多6张）
  → 提交 → 自动生成标准寻宠卡片
  → 点击"生成短视频素材"
  → AI 生成完整视频脚本 + 标签
  → 一键复制 → 粘贴到抖音/小红书/剪映
```

### 3.2 领养匹配流程
```
领养人进入"领养"模块 → 填写申请表
（城市/住房/经验/空间/偏好）
  → 系统执行标签权重匹配算法
  → 展示匹配结果（按匹配度%排序）
  → 查看详情 → 收藏 → 留言咨询
  OR
  → 打开 Coze Bot → 对话式获取推荐
```

### 3.3 AI 短视频生成流程
```
详情页点击"生成短视频素材"
  → 抓取宠物图文信息
  → 优先调用 DeepSeek API（需配置 Key）
    ├── 成功 → 展示 AI 生成结果
    └── 失败 → 自动降级本地文案模板
  → 输出：温情文案 + 科普文案 + 分镜 + 标题 + 标签 + BGM 建议
  → 一键复制全部素材
```

## 四、AI 匹配算法设计

### 4.1 标签权重体系

| 匹配维度 | 权重 | 评估方式 |
|----------|------|----------|
| 城市匹配 | 15% | 同城 100 | 同省 30 | 跨省 10 |
| 宠物类型偏好 | 25% | 精确匹配 100 | 不限 80 | 不匹配 20 |
| 品种偏好 | 20% | 精确匹配 100 | 模糊匹配 85 | 不限 60 |
| 空间适配 | 20% | 自有+大空间 100 | 租房+小型 90 | 租房+大型 40 |
| 养宠经验适配 | 10% | 经验+高难度宠物 100 | 新手+易养宠物 90 |
| 性格/生活方式 | 10% | 语义关键词匹配 0-100 |

### 4.2 Coze Bot 增强（规划中）
- 自然语言输入 → LLM 提取结构化条件 → 调用匹配引擎 → 自然语言输出推荐结果
- 优势：无需填表单，对话式交互降低使用门槛
