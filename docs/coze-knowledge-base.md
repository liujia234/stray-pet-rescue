# 领养知识库

## 新手领养指南
第一次养宠物需要准备：
1. 基础用品：食碗、水碗、猫砂盆/尿垫、窝
2. 食品：幼猫/幼犬粮、零食
3. 医疗：找好附近的宠物医院，建立健康档案
4. 安全：封窗（养猫）、收好危险物品
5. 时间：每天至少30分钟陪伴时间

## 猫狗饲养成本估算
- 猫咪月均：200-500元（猫粮 + 猫砂 + 零食 + 驱虫）
- 小型犬月均：300-600元（狗粮 + 尿垫 + 零食 + 驱虫）
- 大型犬月均：500-1000元（狗粮量大 + 零食 + 驱虫）
- 首年额外支出：疫苗约300-500元，绝育约500-1500元

## 租房养宠注意事项
1. 签合同前确认房东是否允许养宠
2. 准备宠物押金（通常1-2个月租金）
3. 做好隔音（猫抓板、狗咬胶减少破坏）
4. 选择小型、安静的品种
5. 保留好宠物医疗记录，搬家时可能需要

## 领养流程
1. 填写领养申请表
2. 救助站审核（1-3个工作日）
3. 上门看宠物，确认"眼缘"
4. 准备宠物用品
5. 签订领养协议
6. 接宠物回家
7. 7天适应期（有问题可联系救助站）

## 如何判断宠物健康状况
1. 眼睛：清澈明亮，无分泌物
2. 鼻子：湿润但不流涕
3. 皮毛：光滑有光泽，无斑秃
4. 精神：活泼好动，反应灵敏
5. 食欲：正常进食，不挑食不厌食
6. 排泄：粪便成形，不稀不硬
