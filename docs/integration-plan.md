## 二、三条联动路径

### 路径 1：小程序内嵌 Coze 聊天页 ✅ 已实现

```
用户在小程序领养页 → 点击「AI 智能对话匹配」
  → 进入聊天页 → 输入需求
  → wx.request → Coze API → 返回 AI 回复
  → 显示在小程序聊天界面
```

**技术实现**：
- `utils/coze-api.js` 封装 API 调用
- `pages/chat/chat` 聊天 UI 页面
- 支持图文消息、Markdown 渲染

**适用环境**：
- ✅ 微信开发者工具模拟器
- ✅ 真机调试模式
- ⚠️ 手机预览模式（受域名白名单限制，需服务器端代理）

### 路径 2：Coze Bot 独立访问 🚧 规划中

```
用户在微信里搜索 Coze Bot →
  直接对话 → Bot 推荐宠物 →
  附小程序链接 → 跳转小程序详情页
```

**技术实现**：
- Coze Bot 发布到「微信客服」渠道
- Bot 回复中嵌入小程序 URL Scheme（如 `wx56c17b23ab4addac://pages/detail/detail?id=xxx`）
- 用户点击链接直接跳转小程序对应页面

**优势**：绕开域名白名单限制，手机端可直接使用

### 路径 3：公众号 + 小程序联动 🚧 规划中

```
用户关注公众号 →
  菜单栏「领养匹配」→ 跳转小程序或打开 Coze Bot
  用户留言 → Coze Bot 自动回复
  新宠物上架 → 公众号模板消息推送
```

## 三、数据流设计

### 3.1 用户数据流转

```
小程序表单数据  ←→  Coze Bot 对话上下文
     │                    │
     └────────┬───────────┘
              │
     ┌────────▼────────┐
     │  统一用户画像     │
     │  (Storage 本地)  │
     │  · 领养条件      │
     │  · 浏览历史      │
     │  · 收藏列表      │
     │  · 对话记录      │
     └─────────────────┘
```

### 3.2 匹配结果一致性

```
小程序匹配引擎 (match-engine.js)
        ⬇ 算法保持一致 ⬇
Coze Bot 匹配节点 (Code Node)
        ⬇
   同一用户 → 同一匹配结果
   小程序看到 85% 匹配的花花
   Coze Bot 推荐相同的花花
```

## 四、用户使用路径对比

| 场景 | 小程序路径 | Coze Bot 路径 |
|------|-----------|---------------|
| 目标明确 | 直接筛选 + 填表 | 太慢，不适合 |
| 目标模糊 | 不知道选什么 | ✅ "我就想养个安静的宠物" |
| 第一次用 | 需要探索功能 | ✅ 对话式引导 |
| 快捷操作 | ✅ 一键收藏、留言 | 对话式操作较慢 |
| 老年人 | 界面复杂 | ✅ 语音/文字聊天 |

> 💡 **结论**：小程序 + Coze Bot 不是替代关系，而是互补关系。小程序覆盖"我知道要什么"，Bot 覆盖"帮我看看什么适合我"。

## 五、商业化扩展思考

### 5.1 宠物用品电商联动
- 领养匹配成功后 → Coze Bot 推荐新手养宠必备清单
- 点击链接 → 跳转小程序商城页（宠物粮、猫砂、窝）

### 5.2 宠物保险推荐
- Bot 对话中根据宠物品种/年龄 → 推荐合适保险
- 导流至合作保险平台，CPS 分成

### 5.3 救助站 SaaS 服务
- 小程序后台 + Coze Bot 自动化客服
- 救助站付费使用高级功能（数据统计、自动回复、视频批量生成）
