# 用户画像（User Persona）

## Persona 1：走失宠主 — 焦虑的小林

### 基础信息
| 项目 | 内容 |
|------|------|
| 姓名 | 小林 |
| 年龄 | 28岁 |
| 职业 | 互联网运营 |
| 城市 | 北京 |
| 宠物 | 金毛"豆豆"，2岁，养了1年半 |

### 典型场景
周五傍晚遛狗时，小区门口放烟花吓到了豆豆，挣脱牵引绳跑丢了。小林找遍了周围 3 公里，在业主群、朋友圈都发了寻狗信息，但没有统一格式，信息分散。

### 核心痛点
- 😰 **焦虑无助**：不知道还能做什么
- 📢 **传播效率低**：朋友圈文字 + 几张照片，没有统一格式
- ⏰ **错过黄金时间**：前 72 小时是最佳寻找期，但信息扩散太慢
- 📱 **不会做短视频**：知道抖音传播效果好，但不会剪辑

### 使用路径
```
发现走失 → 打开小程序 → "寻宠上报"
  → 填写信息 + GPS定位 + 上传照片
  → 生成标准寻宠卡片 → 转发到微信群
  → 生成短视频素材 → 复制到抖音发布
  → 有线索 → 通过卡片上的电话联系
```

### 产品期望
> "我不需要复杂的操作，只要几步就能生成一个看得过去的寻宠启事和短视频，帮我把信息扩散出去。"

## Persona 2：热心市民 — 大学生阿杰

### 基础信息
| 项目 | 内容 |
|------|------|
| 姓名 | 阿杰 |
| 年龄 | 21岁 |
| 职业 | 大三学生 |
| 城市 | 杭州 |
| 场景 | 放学路上捡到流浪猫 |

### 典型场景
下雨天在校园车棚下发现一只全身湿透的小黑猫，瑟瑟发抖。阿杰用外套把它裹起来带去宠物医院，但之后不知道该怎么办——自己宿舍不能养，又不知道附近有没有救助站。

### 核心痛点
- 🤷 **不知道怎么办**：捡到流浪动物后该做什么？
- 🏥 **找不到救助资源**：不知道附近哪有救助站
- 📋 **不知道怎么写招领启事**：怎么写能帮它找到原主人？

### 使用路径
```
捡到流浪猫 → 打开小程序 → "拾宠招领"
  → 填写特征 + 自动定位发现地点
  → 上传照片 → 发布
  → 系统自动展示附近救助站信息
  → 好心人/原主人看到后联系
```

### 产品期望
> "我只需要拍个照、填几个信息，剩下的系统帮我搞定。如果能直接帮我联系到救助站就更好了。"

## Persona 3：救助站负责人 — 李站长

### 基础信息
| 项目 | 内容 |
|------|------|
| 姓名 | 李站长 |
| 年龄 | 52岁 |
| 职业 | 望京流浪动物救助中心负责人 |
| 城市 | 北京 |
| 规模 | 收容 50+ 只猫狗，3 名志愿者 |

### 典型场景
救助站每天收到各种求助电话，收容的流浪动物越来越多。李站长用 Excel 记录每只动物的信息，但领养转化率很低——很多人来了看一眼就走了，觉得"没有心动的"。

### 核心痛点
- 📊 **管理效率低**：Excel 管理几十只动物，增删改查很麻烦
- 📢 **宣传能力弱**：不会做短视频，朋友圈发发照片效果有限
- 💔 **领养转化率低**：来看的人多，真的领走的少
- 💰 **募捐效果差**：发布的募捐信息阅读量很低

### 使用路径
```
每天打开小程序 → 登录救助站后台
  → 查看数据看板（今日上报/新收容）
  → 新增收容宠物信息
  → 为待领养宠物生成短视频素材 → 发抖音/小红书
  → 发布周末线下领养日活动公告
  → 发布紧急猫粮募捐公告
```

### 产品期望
> "能帮我把每只动物的故事讲好，让合适的人看到它、喜欢它、领走它。最好还能帮我管理这些信息，别让我再用 Excel 了。"

## Persona 4：领养意向者 — 白领小张

### 基础信息
| 项目 | 内容 |
|------|------|
| 姓名 | 小张 |
| 年龄 | 26岁 |
| 职业 | 程序员 |
| 城市 | 上海 |
| 住房 | 租房，40㎡ 一居室 |

### 典型场景
一个人在大城市工作，下班回家觉得冷清，想养一只猫做伴。知道"领养代替购买"但不知道去哪领、怎么领、领回来要准备什么。在闲鱼上看过，但信息杂乱，不信任来源。

### 核心痛点
- 🔍 **不知道去哪找**：想领养但不知道正规渠道
- ❓ **不知道怎么选**：第一次养宠，不知道什么品种适合自己
- 😕 **怕养不好**：担心自己的条件不适合养宠物
- 🏠 **担心房东不同意**：租房养宠的顾虑

### 使用路径
```
想养猫 → 打开小程序 → 填写领养申请表
（上海/租房/新手/安静/偏好猫咪）
  → 系统智能匹配 → 展示 Top 5 匹配结果
  → 查看详情 → 收藏 3 只
  → 在线留言咨询救助站
  → OR 打开 Coze Bot 对话式匹配
  → 联系救助站 → 上门看猫 → 领养成功
```

### 产品期望
> "帮我找到一只适合我条件的猫，告诉我该怎么准备，让我有信心我能养好它。"
